###  [Blog 1 - KIRO POWERS](3.1-Blog1/)
This blog introduces the Powers feature in Amazon Kiro, which allows you to package all the tools, guides, and automation into a single unit and share it with the entire team instead of manually configuring it every time a new project starts. This is an step forward that allow the team use the same AI setup, while also addressing the problem of wasted tokens and reduced AI focus.

###  [Blog 2 - AMAZON RDS AUTOMATION ON SCHEDULE](3.2-Blog2/)
This blog post introduces how to automatically turn Amazon RDS on and off on a schedule using AWS Systems Manager Maintenance Windows, instead of building Lambda modules and manually calling APIs. This helps optimize costs for development, testing, or staging environments that don't need to run 24/7.

###  [Blog 3 - Foundational Knowledge – A Solid Launchpad for Conquering Cloud Computing](3.3-Blog3/)
This blog shares a personal perspective on how a solid foundation in areas such as System Design, Networking, APIs, and Databases has made the process of learning AWS faster and more intuitive.

###  [Blog 4 - BUYING SAVINGS PLANS BEFORE RIGHTSIZING CAN MAKE YOU OPTIMIZE COSTS IN THE WRONG ORDER](3.4-Blog4/)
This blog emphasizes the importance of rightsizing before purchasing Savings Plans to avoid locking spend into over-provisioned resources. It also highlights the new AWS Cost Efficiency widget in Billing and Cost Management Dashboards, which enables daily cost efficiency tracking based on the Understanding your cost efficiency metric.
